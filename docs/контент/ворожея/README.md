## Как это сделано и что из этого автоматизируется

| Шаг | Сейчас | В конвейере |
|---|---|---|
| Распознать текст и время каждого слова | автоматически (нейросеть по аудио) | автоматически; если брат даёт готовый текст, нейросеть только расставляет время |
| Сетка ударов песни | автоматически | автоматически |
| Выбрать куски песни (хук, припев, куплет) | я выбирала на слух по тексту | полуавтоматически: конвейер предлагает, человек утверждает |
| Собрать ролик (фон, текст в такт, эффекты, концовка) | один шаблон, ролик описывается коротким конфигом | автоматически; новый трек — это новый конфиг |
| Картинки (досье, пророчества, сторис) | шаблоны | автоматически, «пророчество дня» хоть на каждый день |
| Подписи и контент-план | писала я | генерирует нейросеть, человек правит |
| Публикация | вручную | по API ВКонтакте и YouTube: отложенные посты на неделю вперёд одним подтверждением |

**Сколько это заняло.** На эту пачку ушёл примерно один рабочий сеанс, и большая часть времени — разовая сборка шаблонов. Следующий трек — это 15–30 минут на выбор кусков и проверку плюс около 10 минут машинного рендера на ролик.

**Ограничения:**
- Фон ролика — неподвижный арт с движением и эффектами, а не видео с «живыми» героями. Новые сцены даст только генерация видео ИИ, но конвейер умеет вставлять и готовые видеокуски, как в шапке ВК.
- Текст из распознавания нужно проверять глазами: ошибка в словах на экране хуже, чем отсутствие текста.

## Если решим автоматизировать

1. Перенести шаблоны в проект (`tools/promo/`) и запускать одной командой: трек → ролики и картинки.
2. Подключить ключи ВК и YouTube для отложенной публикации.
3. Бот «Ворожея» в сообщениях сообщества: гадание в личке, связь слушателей с сообществом.
4. Раз в неделю — короткий отчёт по Метрике и статистике ВК: что зашло, что повторить.
