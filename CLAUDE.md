## Как мы работаем

### В начале разговора и после /compact
1. Перечитать этот раздел.
2. Восстановить состояние по фактам, а не по пересказу: `git status`, `git log -3`; живы ли Глашатай и сайт
   (команда — в `CLAUDE.local.md`).
3. Пересказ прошлого — не согласие: «да» на прошлые шаги не переносится. Решённое не переспрашивать и не переделывать.

### Общение
- Сначала ответ на заданный вопрос. По-русски, просто, коротко, без канцелярита; итог — что изменилось для группы
  и для того, кто публикует, без внутренностей (файлы, переменные, команды), если не спросили.
- Словарь: «да» — согласие только на обсуждённое; «давай» — делать предложенное, не расширяя;
  «дальше» / «делай что нужно» — продолжать, но это **не** согласие на коммит; «тормози» — сразу остановиться;
  **«пушь»** — коммит, `git push origin dev` и выкладка сайта (только обсуждённое).
  Пишут голосом: опечатки, обрывки и текст в английской раскладке — норма, смысл угадывать по контексту.
- Не утверждать непроверенное: что проверено — сказать прямо, что нет — так и сказать.
- Итог работы — до 8 строк: что сделано → что изменилось → что дальше и что нужно от человека.

### Перед любым изменением
1. Найти причину, а не заплатку: не работает у одного поста или площадки — причина в общем коде.
2. Крупная задача — сначала короткий план (шаг → как проверю), потом код. Одна правка за раз, без «заодно».
3. Контент (подписи, посты, ролики, лор) — в Глашатай только черновиком; «Утвердить» жмёт человек.

## Команды

```bash
npm run check        # всё сразу: линтер, тесты Глашатая, тест сайта в Chrome — перед каждым коммитом
npm test             # только тесты
npm run lint         # ESLint (сайт, Глашатай, тесты)
cd tools/autopost && npm run dev               # Глашатай локально — только тестовый режим (AUTOPOST_DRY=1)
cd tools/autopost && npm run plan -- plans/<файл>.js   # контент-план → черновики (на сервере — с его настройками)
DEPLOY_HOST=<хост> sh tools/autopost/deploy/deploy.sh  # выкладка Глашатая; сначала — ничего не публикуется
DEPLOY_HOST=<хост> sh tools/deploy-site.sh             # выкладка сайта (часть «пушь»)
```

## Карта кода
- Сайт: `data.js` — герои, песни, пророчества, ссылки «слушать»; `app.js` — экраны и гадание; `map.js`, `embers.js`;
  `opt/` — сжатые картинки (`tools/optimize.py`).
- Глашатай: `publish.js` — очередь и правила публикации; `platforms/` — по файлу на площадку; `notify.js` — бот Telegram;
  `analytics.js` — цифры и Метрика; `oracle.js` — Ворожея в комментариях; `plans/` — контент-планы; `web/` — кабинет.
- Контент: `docs/контент/стратегия-площадок.md`, контент-планы релизов, исходники роликов, оформление профилей.
- Решения — `docs/change_log.md`. Карта разошлась с кодом — поправить карту и `docs/spec.md`.

## Проверка
- Перед коммитом — `npm run check`, всё зелёное. Баг — сначала тест, который его ловит, потом исправление.
- Изменил сайт — тест сайта должен пройти в Chrome; заметная правка кода — проверяющий агент `oskolki-reviewer`.
- Глашатай на ноутбуке — только тестовый режим: боевой запуск даст двойные публикации.

## Выкладка и сервер
- Коммит и выкладка — только по «пушь». Решение — строкой в `docs/change_log.md`.
- Глашатай выкладывать, когда ничего не публикуется (нет публикаций в статусе «публикуется»).
- **Сервер общий** с рабочими проектами Владислава (подробности — `CLAUDE.local.md`): их не трогать без прямого разрешения;
  перед перезагрузкой nginx — `nginx -t`, только `reload`. Глашатай ограничен сильнее всех и останавливается первым.
- Telegram, Instagram, TikTok и YouTube из России — через прокси; VK и Яндекс — напрямую. Прокси общий — менять только с согласия.

## Нельзя
- Просить ключи и токены в чат; класть их в команды и git — их вставляют в кабинет Глашатая.
- Отправлять личные данные Владислава и Ярослава во внешние сервисы.
- Публиковать контент без утверждения человеком; постить в VK и TikTok от имени Глашатая — там публикует человек.
- Выдумывать лор; платные сервисы и рекламу — без согласия; функции и настройки, о которых не просили.

## Словарь
- **Глашатай** — наш сервис автопостинга; **кабинет** — его сайт; **бот** — его Telegram-бот (пакеты, напоминания).
- **Пост** — что публикуем; **публикация** — пост на одной площадке со своим временем и статусом.
- **Пакет** — файл + подпись + комментарий для ручной публикации (VK, TikTok); **«✓ Выложил»** — отметка, что вышло.
- **Утвердить** — человек разрешил публикацию; **в очередь** — выйдет в своё время.
- **Ворожея отвечает** — гадание в комментариях на слово «расклад»; **отряд** — Айла, Мири, Вулкан, Ильви.
- **Летопись отряда** — канал Telegram; **кодекс** — сайт.

## Как писать код (Karpathy, кратко)
1. Думать до кода: допущения — вслух, неясно — спросить.
2. Минимум кода, который решает задачу; без абстракций и «на будущее».
3. Точечные правки: менять только нужное, чужой код не «улучшать», свой мусор убирать.
4. Цель проверяема: «исправить баг» → «тест, который его ловит, проходит».
