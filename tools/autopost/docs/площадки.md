# Площадки: что можно публиковать по API

Разведка от 17.11.2026 по официальной документации. Ссылки на источники приведены в каждом разделе.
- **[Подтв.]** — прочитано в официальной документации.
- **[?]** — не подтверждено. Это нужно проверить на живом аккаунте и записать сюда.

## Сводка

| Площадка | Что публикуем сами | Что остаётся человеку | Главное ограничение |
|---|---|---|---|
| ВКонтакте | посты с картинками, истории | клипы и видео (выложить по «Пакету»), трек в релизном посте | открытого API для клипов нет; видео — только с особым правом от поддержки |
| YouTube | Shorts сразу публично, с названием, описанием и тегами | ничего | 100 загрузок в сутки на проект |
| Instagram | Reels, фото, карусели, истории | истории со стикером-ссылкой | из РФ — только через прокси; файлы Meta забирает по публичной ссылке |
| TikTok | черновик ролика во «Входящих» приложения | нажать «Опубликовать» в приложении, вставить подпись | без аудита — только приватно; аккаунт из РФ загружать не может |

Уровни поддержки взяты из Нейро-продюсера (`docs/product/channels.md`):
- **авто** — сервис публикует сам;
- **пакет** — сервис готовит подпись и файлы и напоминает о публикации. Человек выкладывает пост и вставляет ссылку.

Любую публикацию можно перевести в «вручную»: этот путь работает всегда.

## ВКонтакте

Страницы методов на dev.vk.com во время разведки открывались частично. Поэтому часть сведений взята из официальной схемы VKCOM/vk-api-schema.

- **Клипы.** Открытого API нет. [Подтв.]
  - В схеме нет раздела `shortVideo`, страницы методов пустые.
  - Вопрос разработчиков к VK от 18.10.2026 ([issue #243](https://github.com/VKCOM/vk-api-schema/issues/243)) остаётся без ответа.
  - Скрытые `shortVideo.*` есть, но работают только у приложений самого VK. [?]

  **Поэтому клип — «пакет»:** сервис напоминает в срок, вы выкладываете клип в приложении и вставляете ссылку.
- **Видео в пост (`video.save`).** Только с ключом пользователя с правом `video`. VK выдаёт его «в исключительных случаях» через devsupport@corp.vk.com. [Подтв.] [video.save](https://dev.vk.com/ru/method/video.save)

  Если поддержка даст право, видео можно перевести в «авто». Пока это пакет.
- **Истории.** `stories.getPhotoUploadServer` / `getVideoUploadServer` + `stories.save` с ключом сообщества (право «истории») работают. [Подтв., по схеме]
  - Ссылка в истории — только на vk.com.
  - Названия полей загрузки (`file` / `video_file`) не подтверждены. [?]
- **Посты (`wall.post`) и фото на стену.** По схеме API нужен ключ пользователя. Нейро-продюсер публикует ключом сообщества. [?]
  - **Проверить первым живым постом.** Если VK откажет (ошибка 27 или 15), пост просто не выйдет и встанет в «Ошибка».
  - Тогда остаются два пути: ключ пользователя через приложение VK ID либо пакет.
- **Ключи пользователя.** Старые способы (implicit flow, `blank.html`) отключены 25.06.2024. [Подтв.]
  - Новые ключи выдаются только через VK ID (OAuth 2.1 + PKCE). Такой ключ живёт 1 час и обновляется.
  - Расширенные права (`wall`, `video`, `photos`) — снова через поддержку.
  - Выданные раньше вечные ключи продолжают работать.
- **Трек из VK Музыки к посту.** API аудио закрыт. Релизный пост с прикреплённым треком выкладывается вручную.
- **Цифры.** `wall.getById`: просмотры, лайки, репосты, комментарии. `stats.*` требует ключ пользователя. [Подтв., по схеме]
- **Лимиты.**
  - Ключ сообщества — 20 запросов в секунду. [Подтв.]
  - Дневные лимиты на посты не опубликованы. Цифры «50 в день» не подтверждены. [?]
- **Идея на потом.** У `wall.post` есть `publish_date`: можно отдавать посты в «Отложенные» самого VK заранее, и тогда они выйдут даже при закрытом ноутбуке.

## YouTube Shorts

- **Вход.** Google OAuth, клиент «Desktop app», адрес вида `http://localhost:4777/oauth/youtube/callback`, PKCE. [Подтв.]
  - Области доступа: `youtube.upload` и `youtube.readonly`.
  - Экран согласия нужно перевести в **«In production»**, проходить проверку не нужно. В режиме «Testing» ключ обновления живёт **7 дней**. [Подтв.]
  - У непроверенного приложения Google при входе покажет предупреждение: «Дополнительно → Перейти». Для своего канала этого достаточно. [?]
- **Приватность.** **С 02.11.2026** видео из непроверенных проектов больше не принудительно приватные (Google отменил правило от 28.07.2020). Аудит не нужен. [Подтв.] [revision history](https://developers.google.com/youtube/v3/revision_history)
- **Квота.** С 01.06.2026 у `videos.insert` своя квота: 100 загрузок в сутки. [Подтв.]
- **Шортс.** Вертикальный или квадратный ролик длиной до 3 минут. Отдельного флага нет, хэштег `#Shorts` не обязателен. [Подтв.]
- **Загрузка.** Возобновляемая (resumable): POST открывает сессию, PUT передаёт файл. [Подтв.]
  - Категория «Музыка» — `categoryId: 10`.
  - `status.containsSyntheticMedia` — пометка о созданном нейросетью контенте; ставим по умолчанию. [Подтв.]
  - Для отложенного выхода есть `publishAt` (только вместе с `private`). Нам он не нужен: время держит очередь.
- **Обложка.** С 03.11.2026 обложку Shorts можно задать через `thumbnails.set`, после обработки видео. [Подтв.] Пока не используем.
- **Цифры.** `videos.list?part=statistics` (стоимость 1).
- **Из РФ.** Явной блокировки googleapis не нашли, но YouTube в РФ замедляют. На сервере в РФ может понадобиться прокси. [?]

## Instagram

- **API.** «Instagram API with Instagram Login» (`graph.instagram.com`): страница Facebook не нужна. Приложение Meta должно быть типа «Business». [Подтв.]
- **Доступ для своего аккаунта.** Стандартного доступа хватает: **проверка приложения и бизнеса не нужна**. [Подтв.]
- **Ключ.**
  - Выдаётся в панели приложения: Instagram → «API setup with Instagram login» → **Generate token**. Живёт 60 дней. [Подтв.]
  - Сервис продлевает его раз в неделю через `ig_refresh_token`. [Подтв.]
  - Свой вход по OAuth на `localhost` Meta, по сообщениям, не принимает, поэтому вставляем ключ. [?]
- **Публикация** в три шага: контейнер → ждём `FINISHED` → `media_publish`. [Подтв.]
  - Поддерживаются Reels, фото, карусели и истории.
  - **Отложенной публикации в API нет**, время держит очередь. [Подтв.]
- **Файлы.**
  - **Видео (Reels, истории-видео) — прямой загрузкой** `upload_type=resumable` → `rupload.facebook.com`, без публичной ссылки. Проверено 17.11.2026 с маркером «единого входа» (`EAA…`, graph.facebook.com): Meta приняла и обработала ролик.
  - **Фото и карусели** Meta берёт только по публичной https-ссылке (`image_url`) — нужна публичная папка (`pubmedia.js`, настройки `MEDIA_*`). Пока Глашатай локальный — фото в Instagram вручную.
- **Ограничения.**
  - Reels: 3 с — 15 мин, до 300 МБ, H.264, 9:16. [Подтв.]
  - Фото: только JPEG до 8 МБ, пропорции от 4:5 до 1.91:1. [Подтв.]
  - Карусель: до 20 элементов. [Подтв.]
  - История: видео 3–60 с, без подписи и стикеров. [Подтв.]
  - Подпись: до 2200 знаков, 30 хэштегов. [Подтв.]
- **Лимит.** 50–100 публикаций за 24 часа (документация противоречит сама себе). Точное число отдаёт `content_publishing_limit`. [Подтв.]
- **Цифры.** `/{media}/insights`: `views`, `reach`, `likes`, `comments`, `shares`, `saved`. Метрики `plays` и `impressions` удалены. [Подтв.]
- **Из РФ.** API закрыт, все вызовы идут через зарубежный прокси (`HTTPS_PROXY`). Файл Meta забирает с нашего сервера напрямую. Пустит ли Meta к российскому серверу — [?], проверить первой публикацией.

## TikTok

- **Прямая публикация без аудита.** Только `SELF_ONLY` («видно мне»), и только если сам аккаунт приватный. [Подтв.]
- **Аудит.** Правила TikTok прямо называют неприемлемыми:
  - «утилиту для выкладки в аккаунты, которыми управляете вы или ваша команда»;
  - приложения «для личного использования».

  **Аудит для группы почти наверняка не пройдёт.** [Подтв.] [guidelines](https://developers.tiktok.com/docs/en/content-sharing-guidelines)
- **Реальный путь — черновик** (`video.upload`): [Подтв.]
  - ролик попадает во «Входящие» TikTok;
  - участник группы открывает уведомление, вставляет подпись и публикует;
  - лимит — 5 ожидающих черновиков в сутки.
- **Вход.** Приложение регистрируем как **Desktop**: так разрешён адрес `http://localhost:ПОРТ`. [Подтв.]
  - В PKCE код вызова — это **hex** от sha256, а не base64url. [Подтв.]
  - Ключ обновления меняется при каждом обновлении: новый сохраняем сразу. [Подтв.]
- **Загрузка.** Файл до 64 МБ уходит одним куском. Для больших файлов — куски от 5 до 64 МБ. Адрес загрузки живёт 1 час. [Подтв.]
- **Цифры.** `/v2/video/query/`: только публичные видео. [Подтв.]
- **РФ.** С 2022 года TikTok не даёт загружать видео аккаунтам из российского региона. Регион определяется по аккаунту, устройству и SIM-карте, а не по IP. [?] Нужен аккаунт, заведённый вне РФ. Проверить одной загрузкой до всего остального.
